# 🎙️ 음성 분석 (Voice Analysis)

휴대폰 브라우저에서 바로 동작하는 **목소리 건강 분석 웹앱(PWA)** 입니다.
설치 없이 마이크로 목소리를 녹음하면, 모든 분석을 **기기 안에서** 처리하고
결과를 한국어 해설과 함께 보여줍니다. 음성 데이터는 서버로 전송되지 않습니다.

> ⚠️ 본 앱은 참고용 정보를 제공하며 의학적 진단을 대체하지 않습니다.
> 증상이 지속되면 이비인후과·음성언어재활 전문가와 상담하세요.

## 기능

### 1) 음성 검사 — 모음 /아/
모음 "아~"를 3~5초 길게 발성해 음성의 안정성을 측정합니다.
- **F0 (기본 주파수)** — 목소리의 높낮이 (성대 진동수)
- **Jitter (지터)** — 주기(주파수) 떨림, local·PPQ5·절대값
- **Shimmer (쉬머)** — 진폭(세기) 떨림, local·dB·APQ5
- **CPPS** — 평활 켑스트럼 피크 돌출도(음질 지표)

### 2) 발화 평가 — 일상 대화
1~3분(최대 5분) 자연스러운 발화를 녹음해 음높이 유지력과 음질을 평가합니다.
- **SFF 분포** — 발화 기본 주파수(Speaking Fundamental Frequency)의 히스토그램·평균·반음 변동
- **CPPS** — Smoothed Cepstral Peak Prominence(평활 켑스트럼 피크 돌출도), 음질 지표
- **음도 일탈(Pitch Breaks)** — 옥타브성 음높이 급변·발성 끊김 빈도(분당)
- 시간에 따른 **음도 곡선(F0 contour)** 시각화

각 지표마다 정상 참고 범위 대비 등급(양호/경계/주의)과 쉬운 해설을 제공합니다.
또한 **세션1 지터 × 세션2 CPPS**를 조합한 **종합 해석**(두 검사가 모두 있을 때)을
제공해, 주기 안정성과 전반 음질을 함께 평가합니다.

### 3) 후두 마사지 — Manual Circumlaryngeal Therapy (MCT)
후두 주변 근육 긴장을 풀어 음성을 편하게 내도록 돕는 마사지 가이드입니다.
- **설명 슬라이드**(준비→설골→갑상설골 공간→후두 하강→발성)와 **시연 영상**
- 영상을 다시 보며 따라 한 뒤, **"검사 다시하기"** 로 세션1 검사를 재시행
- **마사지 전·후 비교**: 수치 변화표 + 막대 비교 + 시간 추이 그래프
- 마사지 후 편안한 음높이를 **세션4 바이오피드백 목표 F0**로 자동 저장
- ※ 시연 영상은 `assets/mct-demo.mp4` 에 넣거나 화면에서 직접 파일을 불러옵니다.

### 4) 실시간 시각적 바이오피드백 — Visual Biofeedback
말하는 동안 현재 F0를 실시간 라인으로 보여주며 목표 음역대로 유도합니다.
- 세션3에서 저장한 **마사지 후 F0**를 **녹색 타겟 박스**로 표시
- 현재 음높이를 흐르는 **실시간 Line 그래프**로 표시(약간의 지연 허용)
- **게임화**: 목표 영역 유지 시 **충전 게이지**가 차고 가득 차면 **별(⭐) 획득**
  (금색 플래시 + 햅틱 진동 + 점수 보너스), 콤보로 충전 가속, 벗어나면 게이지 서서히 감소(복귀 유도)
- **유도**: 목표까지 남은 Hz·방향 안내, 목표 진입 시 박스 발광·맥동 표시
- **종료 요약**: 별 개수·적중률·최고 유지로 등급(A/B/C) 부여 → 재도전 동기

### 5) 종단적 추적 대시보드 — Longitudinal Tracking
검사 이력을 시간에 따라 추적합니다. **달력 / 주간** 모드 전환.
- **달력 모드**: 일자별 F0 평균·CPPS 수치와 마사지 수행 여부(💆) 기록
- **주간 모드**: 최근 14일 F0·CPPS·지터·쉬머를 **꺾은선 그래프**로 표시
- 모든 기록은 기기 내 `localStorage`에 저장(브라우저별 로컬 보관)

## 분석 방법 (요약)

| 항목 | 알고리즘 |
|------|----------|
| F0 검출 | YIN (누적 평균 정규화 차분 + 포물선 보간) |
| Jitter / Shimmer | point-process 방식: 피치 컨투어로 주기 예측 → 교차상관(서브샘플 보간)으로 글로탈 펄스 위치 보정 → Praat식 제약(주기비 1.3·진폭비 1.6 초과 쌍 제외) |
| CPPS | 로그파워 켑스트럼을 quefrency·시간으로 평활 → F0 대역 피크 vs. 전체 quefrency 회귀선 돌출도 |
| Pitch Breaks | 인접 유성 프레임의 옥타브성 도약 + 발성 중 끊김 검출 |

- 배치 분석 표본화율: 16 kHz로 다운샘플 (음성 F0 범위에 충분, 계산량 절감)
- 프레임 40 ms / 홉 10 ms, Hann 윈도우
- FFT/IFFT는 의존성 없는 순수 JS radix-2 구현 (`js/fft.js`)
- 세션4 실시간 피치: 원본 표본화율 그대로 YIN(고음 해상도 확보) +
  중앙값·EMA 평활 + 옥타브 오류 가드 (여성 고음 정확도 보완)

## 실행 방법

마이크 접근은 **HTTPS(또는 localhost)** 에서만 허용됩니다.

### 로컬에서 실행
```bash
# 저장소 폴더에서
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```
같은 와이파이의 휴대폰에서 접속하려면 PC의 로컬 IP를 사용하되, 모바일
크롬/사파리는 보안 컨텍스트(HTTPS)를 요구하므로 아래 배포 방식을 권장합니다.

### GitHub Pages 배포 (권장)
1. 이 저장소를 GitHub에 푸시
2. **Settings → Pages → Branch** 에서 배포 브랜치 선택
3. 발급된 `https://...github.io/...` 주소를 휴대폰에서 열기
4. 사파리/크롬의 **"홈 화면에 추가"** 로 앱처럼 설치 (오프라인 동작)

## 참고 기준치 (정상 성인, 문헌 일반값)
- Jitter (local) < 1.04 %
- Shimmer (local) < 3.81 % (≈ 0.35 dB)
- CPPS: 높을수록 양호 (발화 대략 ≥7dB 양호·<4dB 주의, 모음 ≥9dB 양호) — 구현 특성상 절대값은 참고용

브라우저·마이크·환경 소음에 따라 절대값은 달라질 수 있으므로,
**같은 환경에서의 추세 비교**에 활용하는 것을 권장합니다.
